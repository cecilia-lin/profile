# Make it yours

1. Create a **public** GitHub repository whose name exactly matches your GitHub username (for example, `yourname/yourname`). If you already have a profile repository, use it.
2. Upload `README.md` and the entire `assets` folder to the repository root. Keep the folder structure intact; the icons use relative paths. You don't need the `preview` or `design` folders on GitHub.
3. Replace every `YOUR_…` and `REPLACE_…` value in `README.md` with your real details. The two bracketed project entries are editable slots, not claims about completed work. Replace them with actual projects or delete those rows. Remove the food app demo link if no demo exists yet.
4. Commit your changes and visit your GitHub profile.

## Included

- `assets/profile-picture.png`: matching 1024 × 1024 house avatar, composed for a circular profile crop. Upload this separately as your GitHub profile picture.
- `README.md`: profile copy with GitHub-compatible Markdown and small inline PNG images.
- `assets/icons/`: five optimized 256 × 256 PNG doodles with transparency. The house displays at 44px; section icons display at 28px.
- `preview/index.html`: local rendering of the README, with light/dark controls. Open it in a browser; it works offline.
- `preview/readme-preview.png`: a static light-mode preview.
- `preview/readme-dark.png` and `preview/readme-mobile.png`: dark-mode and phone-width previews.
- `design/icon-prompts.json`: the generation prompts used for this set (built-in image_gen).

The preview approximates GitHub's README layout; GitHub controls the final fonts, spacing, background, and link colors. The journal feel comes from the copy, numbered headings, restrained layout, and doodles. All icon backgrounds are transparent.
